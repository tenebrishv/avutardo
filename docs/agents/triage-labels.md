# Etiquetas de triage

Las skills hablan de cinco roles de triage canónicos. Este archivo los traduce
a las etiquetas que usa el tracker de este repo.

| Etiqueta en mattpocock/skills | Etiqueta en nuestro tracker | Significado                                   |
| ----------------------------- | --------------------------- | --------------------------------------------- |
| `needs-triage`                | `needs-triage`              | Alguien del equipo tiene que evaluarla        |
| `needs-info`                  | `needs-info`                | Espera más información de quien la abrió      |
| `ready-for-agent`             | `ready-for-agent`           | Especificada del todo, lista para un agente   |
| `ready-for-human`             | `ready-for-human`           | La tiene que implementar una persona          |
| `wontfix`                     | `wontfix`                   | No se va a hacer                              |

Cuando una skill nombra un rol (por ejemplo, "poner la etiqueta de lista para
un agente"), usar la etiqueta de la columna del medio.

Para cambiar el vocabulario, editar esa columna.
